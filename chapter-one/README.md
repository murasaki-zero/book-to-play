# 书中练习室 · 游戏设计艺术第2版

本地学习工程。34章、136个单元已可用；2026-10-04针对质量检查重做第5—34章120个单元。前4章基础保留。课程是重点概念的互动学习路线，原书的论证、案例和细节通过扫描页继续阅读。

第5—34章有15种实际操作或构建形式：关系图、排序、预算取舍、作品编辑、状态机、骰子抽样、资源轨迹、收益表、灯阵谜题、兴趣曲线、界面对照、地图寻路、配色场景、回忆任务、收入成本推算。每章至少两种形式。章末作品的名称和自评项也按主题编写。

## 打开

```sh
cd '/Volumes/MBA/项目/Game_STU/chapter-one'

```

打开 [开始学习](http://127.0.0.1:4173/开始学习.html)，已有页面刷新后读取新版。无需npm依赖，Node.js18+。`dist/index.html`为分文件入口；双击`dist/开始学习.html`可以离线打开，需保留旁边的`assets/`，本地文件保存受浏览器策略影响。

## 保存与复习

- 笔记、参数、连线、作品与新版实验局面会随操作存到本浏览器。明确保存的实验保留最多20条；第2—4章旧实验未完成局面仍在内存。
- 原键`book-to-play:schell-2:workbook:v2`保持；旧第一章v1迁移仍支持。已有完成、复习日期与笔记保留。旧完成与作品会提示重新核对新版要点，不自动算新版操作证据。
- 比较类单元必须保存两种不同条件；重复保存同一结果不会凑次数。单元完成还需自己的解释，表示做过并记录，不表示自动判定掌握。
- 学习笔记页导出全书Markdown、备份JSON。导出弹窗同时提供完整文字与下载按钮。跨浏览器、协议或端口前请备份。
- 恢复全书备份替换全部进度；v1备份仅替换第一章。恢复前会提供当前存档备份。不要在4173进行测试恢复。
